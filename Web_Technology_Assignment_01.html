01-Login-Page/main.js (Vanilla JavaScript Form Validation)
function login() {
  let u = document.getElementById("user").value.trim();
  let p = document.getElementById("pass").value.trim();
  let msg = document.getElementById("msg");

  if (u && p) {
    msg.innerText = "Login details entered!";
    msg.style.color = "#047857";
  } else {
    msg.innerText = "Enter username and password.";
    msg.style.color = "#b91c1c";
  }
}

Question 03: CSS Box Model Concept
3. Explain the concept of Box model in CSS.

Answer: Every HTML element is represented as a rectangular box. The CSS Box Model governs how elements occupy space on a webpage through four hierarchical layers:

MARGIN (Outer transparent spacing between elements)
BORDER (Line enclosing the padding and content)
PADDING (Inner transparent space around content)
CONTENT (Actual text, image, or video)
CSS Box Model Syntax
div.box-example {
  width: 250px;           /* Content Area Width */
  padding: 15px;          /* Space between content and border */
  border: 2px solid #000; /* Border surrounding padding */
  margin: 20px;           /* Space outside border from other elements */
  box-sizing: border-box; /* Includes padding & border inside total width */
}
Question 04: JavaScript Array, Object & Function
4. Explain the concept of array, object and function in javascript.

Answer:

  • 1. Array: An ordered, zero-indexed data structure storing multiple elements under a single variable. (e.g. let fruits = ["Apple", "Mango", "Banana"];).
  • 2. Object: A structured data collection storing key-value pairs representing entity properties. (e.g. let student = { name: "Amit", rollNo: 1, cetScore: 85 };).
  • 3. Function: A reusable block of code that performs an action when executed/invoked. (e.g. function add(a, b) { return a + b; }).
